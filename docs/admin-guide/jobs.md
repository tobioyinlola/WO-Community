# Jobs

**Where:** Admin > Jobs. Members' Jobs page has a **Post a job** button; for an admin it opens the
admin form, so the job goes live at once.

**Applications are never taken on WO Community.** A job gives an application link (https only), an
email address, or both. The member sees the site it opens before they leave, and the email button
opens a message with the subject "Application: <job title>". Every job page says "Applications are
handled directly by the employer."

**Who posts, who approves.** An admin's job is live at once. A member's job waits for review
(unless the board is set to publish at once). The member sees the state of their own jobs, and can
edit and send back a rejected one. Editing a live member job sends it back to review only when the
title, company, description or how to apply changes.

**Tabs:** Active, Pending review, Rejected, Closed or expired, each with a count, plus search,
company, type and date filters. Open a job to read it all, then Approve, Reject (a reason is
required and sent to the poster), Close, Reopen, Edit or Remove. Tick several pending jobs to
approve them together. The poster is told about every decision.

A job expires after 30 days by default (Settings > Community), the poster gets a reminder first and
can renew it.
