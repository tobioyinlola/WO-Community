# Members

**Where:** Admin > Members. Click a member's name to open them in a drawer. The address
`/admin/members/<id>` opens the same drawer over the list, so it can be shared and the back button
closes it.

**Sections:** Profile, Account (email, joined, last active, invited by, referred by, who approved
them), Activity (posts, comments, events attended, jobs posted), Learning (courses and certificates),
Mentorship (status, availability, pricing, sessions), Support (open requests) and Audit (their last
ten entries, with a link to the full log filtered to them).

**Actions** (each needs its own permission and is audited): Approve or Reject a pending member,
Suspend or Reinstate, Change role (console roles; super admins only), Resend verification email,
and Delete, which asks you to type the member's email first. Opening a member is also logged, since
it shows personal details.
