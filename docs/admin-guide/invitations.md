# Invitations

**Where:** Admin > Invitations > Invite people.

Type or paste addresses. Enter, comma, space, semicolon, Tab or leaving the box turns the text into a
chip; pasting a list makes one chip each (up to 200 at a time, with a counter). The X on a chip, or
Backspace in the empty box, removes it.

- A malformed address is shown as an error chip with the reason, not by colour alone.
- A repeated address is merged, with a note.
- The server checks who is already here: **Already a member** and **Invite pending** chips are not
  sent.
- The button says how many will go ("Send 12 invitations"). You can pick a role and add a note of up
  to 500 characters that goes in the email.
- After sending you see a result for each address: sent, or skipped with the reason.

Sending twice by accident does nothing the second time (each send carries a key). Registering through
an invitation approves the member at once, as before. Only a super admin can invite a team role.
Each send is audited.
